ДСК БАРТ — готовый статический сайт

Содержимое:
- index.html — главная страница
- style.css — дизайн и адаптация под телефон
- script.js — мобильное меню, поиск, фильтры и сортировка каталога
- assets/ — фотографии изделий и QR-коды соцсетей

Публикация на GitHub Pages:
1. Распакуйте архив.
2. Загрузите ВСЕ содержимое папки DSK_BART_READY в корень репозитория GitHub (включая папку assets).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Дождитесь публикации и откройте выданный GitHub Pages URL.

Важно: не загружайте только index.html — папка assets и файлы style.css/script.js обязательны.
Контакты, телефоны, почта и соцсети уже встроены в сайт. Форма заявки не имитируется: для отправки заявок на сервер нужен отдельный backend.
